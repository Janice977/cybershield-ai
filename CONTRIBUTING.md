# Como contribuir

1. Abra uma issue descrevendo o problema ou proposta.
2. Faça fork e crie uma branch pequena e descritiva.
3. Inclua testes e documentação; execute `python -m pytest -q`.
4. Abra pull request com explicação, dados sintéticos e resultados.
5. Não publique dados pessoais, credenciais, exploits, amostras reais de malware ou registros de terceiros.
6. Relate vulnerabilidades de modo privado, conforme SECURITY.md.

Código de conduta: CODE_OF_CONDUCT.md.

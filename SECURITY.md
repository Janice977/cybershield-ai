# Política de segurança

Não publique detalhes de vulnerabilidades exploráveis em issues públicas. Contate o mantenedor por canal privado indicado no perfil do repositório até que exista canal oficial. Não há SLA de correção ou resposta. Não execute com logs reais não autorizados, nem exponha o app publicamente sem controles adicionais. O projeto não executa ações em sistemas externos.


## Relatar vulnerabilidade em privado

Se o recurso estiver habilitado, use **Security → Advisories → Report a vulnerability** no GitHub. Não abra Issues públicas com detalhes exploráveis, credenciais ou dados pessoais. Caso o recurso não esteja disponível, peça um canal privado ao mantenedor sem publicar os detalhes. Não há SLA formal.
